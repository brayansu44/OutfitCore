# OutfitCore

OutfitCore es una aplicación web orientada a la gestión de inventario y diferentes procesos operativos de una organización. El sistema integra módulos para administrar productos, movimientos, compras, ventas, bodegas, proveedores y otros componentes relacionados con la operación del negocio.

## Funcionalidades principales

- Gestión de productos e inventario.
- Control de movimientos y existencias.
- Gestión de compras y ventas.
- Administración de bodegas e insumos.
- Gestión de proveedores.
- Administración de locales.
- Gestión de usuarios y cuentas.
- Registro de gastos.
- Gestión de notificaciones.
- Trazabilidad de operaciones.

## Tecnologías utilizadas

- Python
- Django
- HTML
- CSS
- JavaScript

## Estructura del proyecto

El sistema está organizado mediante diferentes módulos de Django, entre ellos:

- `Producto`: gestión de productos.
- `Movimientos`: control de movimientos de inventario.
- `Compras`: gestión de compras.
- `Ventas`: gestión de ventas.
- `bodega`: administración de bodegas e insumos.
- `proveedores`: gestión de proveedores.
- `locales`: administración de locales.
- `gastos`: registro y gestión de gastos.
- `notificaciones`: gestión de notificaciones.
- `trazabilidad`: seguimiento de operaciones.
- `usuarios`: gestión de usuarios.

## Objetivo del proyecto

El proyecto busca centralizar diferentes procesos relacionados con inventario y operación empresarial en una aplicación web, aplicando conceptos de desarrollo backend, organización modular y gestión de información.
